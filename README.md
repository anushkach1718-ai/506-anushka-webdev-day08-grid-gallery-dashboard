
# ✦ PixelSpace – Creative Dashboard

## 📌 Project Overview
PixelSpace is a colorful and responsive Creative Dashboard created using HTML5 and CSS3.

This project demonstrates CSS Grid concepts through a modern dashboard layout, photo gallery, statistics cards, and activity sections.

## ✨ Features
- Responsive dashboard layout
- Sidebar navigation menu
- Statistics cards
- CSS Grid photo gallery
- Recent activity section
- Project progress bars
- Hover effects and pastel colors
- Mobile-friendly design

## 🛠️ Technologies Used
- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries

## 📂 Project Structure
```text
project/
├── index.html
├── style.css
└── README.md
```

## 🚀 How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open index.html.
4. Run using Live Server.

## 🎯 Learning Outcomes
- Understanding CSS Grid layouts
- Using grid-template-columns and grid-template-rows
- Creating responsive layouts
- Using CSS Flexbox
- Applying hover effects and media queries
